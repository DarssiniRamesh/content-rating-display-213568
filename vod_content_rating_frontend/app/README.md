# App module (Android TV-ready)

- Package: org.example.app
- Entry: org.example.app.TvSplashRedirectActivity (MAIN/LAUNCHER)
- TV Index: org.example.app.tv.TvIndexActivity
- TV Instructions: org.example.app.tv.TvInstructionsActivity

Build commands (from project root `vod_content_rating_frontend/`):
- Assemble debug: `./gradlew :app:assembleDebug`
- Install debug (device/emulator): `./gradlew :app:installDebug`
