# Índice Overview

- Launcher: ÍndiceActivity
- Primary actions:
  - Button: Start Playback (QA) -> opens the rating screen with seeded content
  - Overflow menu:
    - Instructions -> InstruccionesActivity
    - Deep Link Help -> shows adb command for `app://rating/show`

Executive Gray styling is applied via Theme.ExecutiveGray.* and setTheme from Activities.
