This package contains Android TV helpers and Activities:

- TvIndexActivity: TV launcher screen for Índice (41:135)
- TvInstructionsActivity: Instrucciones (41:206)
- WebViewTvUtils: Centralized WebView configuration for TV
- TvWebViewHelper: WebViewClient tailored for TV navigation and DPAD focus
- TvDpadHelper: Common DPAD handlers

Resources:
- res/layout-tv/: TV layouts
- res/values-tv/: TV strings, styles, themes, colors
- res/drawable/: focus states (focus_ring), tv_focus_container
- app/src/main/assets/: HTML/CSS/JS and images for WebView rendering
