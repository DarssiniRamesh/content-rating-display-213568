Ayuda de navegación (Android TV)

Consejos:
  • Usa las flechas del control remoto (DPAD) para moverte entre elementos.
  • Presiona OK/Enter para seleccionar.
  • En pantallas largas, usa flechas arriba/abajo para paginar dentro del contenido.

Flujo de navegación:

  • Inicio: Índice de prototipos
  • Selecciona "Continuar" para ir a Instrucciones
  • En Instrucciones, activa "Entendido" para continuar (flujo siguiente en desarrollo)
