TV Assets Overview

- ndice-41-135.html and instrucciones-41-206.html are the base screens exported from design, using common.css.
- tv-webview.css: TV-optimized CSS (contrast, focus outlines, scrollbars).
- tv-dpad-scroll.js: Enables DPAD arrow scrolling within WebView content on TV.
- indice-41-135.wrapper.html and instrucciones-41-206.wrapper.html: wrappers including TV CSS/JS.
- index_tv.html and instrucciones_tv.html: convenience entry points that load the base screens inside an iframe with TV styling applied.
