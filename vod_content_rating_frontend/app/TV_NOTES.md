# TV Activities Overview

- org.example.app.tv.TvIndexActivity (LEANBACK_LAUNCHER)
- org.example.app.tv.TvInstructionsActivity

Both activities:
- Support DPAD navigation and remote input.
- Use native focusable buttons with a visible focus ring.
- Render Figma-derived HTML via WebView from file:///android_asset/.
- Provide overscan-safe margins and TV-friendly font sizes.
- Are declared in AndroidManifest with appropriate TV flags.
