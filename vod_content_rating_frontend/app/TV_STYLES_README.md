TV styling notes

- Use style="@style/TvButton.Primary" for primary action buttons on TV.
- Use style="@style/TvSurface.Focusable" for containers that should show a focus ring when focused (e.g., WebView container).
- Colors live in res/values-tv/colors.xml; themes in res/values-tv/themes.xml.
- Focus drawables: res/drawable/focus_ring_primary_tv.xml, res/drawable/focus_ring_surface.xml.
