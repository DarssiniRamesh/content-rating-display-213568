# Content Rating Display Workspace

This workspace hosts the Android app in:
- vod_content_rating_frontend/

Build commands:
- From workspace root (bridged): ./gradlew :app:assembleDebug
- Or cd vod_content_rating_frontend and run: ./gradlew :app:assembleDebug

Project type:
- Android (Kotlin), Gradle Declarative (.dcl). Compatibility build.gradle/settings.gradle files are included for tools that expect traditional Gradle.
