Android Gradle Root

This directory is the Gradle root for the Android project in this repository.

Modules:
- app/
- list/
- utilities/

Build:
- ./gradlew build

Launch (Android TV):
- Install and launch the LEANBACK launcher Activity: org.example.app.tv.TvIndexActivity

Notes:
- The repository root contains forwarding helpers for tools that scan only the repo root. If your analyzer still cannot detect the root, run it from this directory.
