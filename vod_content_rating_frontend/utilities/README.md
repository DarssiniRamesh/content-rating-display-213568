# Utilities Module

This Kotlin library provides simple string utilities and a build marker used by the app.

Build from Android workspace root:
- ../gradlew :utilities:assemble

Primary sources:
- src/main/kotlin/org/example/utilities/StringUtils.kt
- src/main/kotlin/org/example/utilities/JoinUtils.kt
- src/main/kotlin/org/example/utilities/SplitUtils.kt
